## 1. Executive Summary & Architecture Overview

This technical specification details the complete ASIC synthesis and physical implementation methodology for the **2x2 MIMO Baseband Processor**. The design is prepared for tapeout on the **Semi-Conductor Laboratory (SCL) 180nm CMOS process (SCL018)** using Cadence's enterprise digital implementation suite. 

To bridge academic pre-silicon prototyping with foundry fabrication, this guide defines a dual-stage flow:
1. **Pre-Silicon Virtual Prototyping:** Executed using the available Cadence 180nm Generic PDK (`gpdk180`) to validate synthesis quality of results (QoR), logic equivalence, place-and-route (P&R) congestion, clock tree synthesis (CTS), and signoff static timing analysis (STA).
2. **Foundry Porting & Tapeout Signoff:** Re-targeting to SCL 180nm standard cells, 1P6M aluminum metallization rules, 1.8V/3.3V dual-voltage level shifters, and wire-bonding I/O pad frames.

## 2. Cadence EDA Toolchain Flow

### 2.1 Logic Synthesis via Cadence Genus
Cadence Genus Synthesis Solution performs logic optimization, technology mapping, and Physical Layout Estimation (PLE) to synthesize behavioral Verilog (generated by MATLAB HDL Coder) into a structural netlist of 180nm standard cell gates.

#### Key Synthesis Objectives:
1. **Technology Mapping:** Translate datapath arithmetic (CORDIC Givens rotation stages, 16-bit complex multipliers, and power-allocation comparators) into primitive logic gates (`NAND`, `NOR`, `AOI`, `OAI`, `ADDF`, `DFFQX4`).
2. **Physical Layout Estimation (PLE):** Utilize physical LEF rules (`gpdk180_tech.lef`, `gpdk180_stdcells.lef`) and wire capacitance tables to compute real interconnect parasitics during mapping, preventing post-route timing discrepancies.
3. **Datapath Optimization:** Configure `set_db / .dp_effort high` to automatically infer carry-lookahead adders and Booth-encoded Wallace tree multipliers for CORDIC pipeline registers.
4. **Hierarchy Preservation:** Enforce `set_db / .auto_ungroup none` on primary computational engines (`alamouti_encoder`, `cordic_2x2_svd`, `water_filling_allocator`, `mmse_sic_core`) to ensure seamless tracing during Conformal LEC and modular floorplanning.

#### Genus Synthesis Command:
```bash
genus -f hdl_asic/07_physical_design_asic/scripts/run_genus_synth.tcl -log genus.log
```

---

### 2.2 Equivalence Checking via Cadence Conformal LEC
Conformal Logic Equivalence Checking (LEC) mathematically proves that the gate-level netlist synthesized by Genus preserves exact Boolean equivalence with the golden RTL from HDL Coder, confirming that optimization transformations did not corrupt state-machine logic or datapath integrity.

#### LEC Methodology:
1. **Golden Design:** Unmapped RTL Verilog source files.
2. **Revised Design:** Synthesized gate-level netlist (`mimo_baseband_top_synth.v`) mapped with 180nm standard cell simulation models (`gpdk180_stdcells.v`).
3. **Key Point Mapping:** Automated alignment of state points (flip-flops, latches, primary inputs, and primary outputs).
4. **Renaming Rules:** Normalize bus indexing transformations incurred during synthesis (e.g., mapping `signal[15]` to `signal_reg_15_`).
5. **Comparison Proof:** Exhaustive BDD (Binary Decision Diagram) and SAT-solver equivalence verification. Target: **0 Non-Equivalent points**, **0 Unmapped points**.

#### Conformal LEC Command:
```bash
lec -xl -nogui -dofile hdl_asic/07_physical_design_asic/scripts/run_conformal_lec.do
```

### 2.3 Physical Implementation via Cadence Innovus
Cadence Innovus transforms the gate-level netlist into a fully routed, DRC/LVS-clean silicon layout.

#### Implementation Pipeline:
1. **Design Initialization & MMMC Setup:**
   - Multi-Mode Multi-Corner (`viewDefinition.tcl`) initializes:
     - **Setup Corner (Worst-Case):** SS process, $V_{DD} = 1.62\text{ V}$ ($-10\%$), $T = 125^\circ\text{C}$, Max RC parasitic corner.
     - **Hold Corner (Best-Case):** FF process, $V_{DD} = 1.98\text{ V}$ ($+10\%$), $T = -40^\circ\text{C}$, Min RC parasitic corner.
     - **Typical Corner:** TT process, $V_{DD} = 1.80\text{ V}$, $T = 25^\circ\text{C}$, Typ RC parasitic corner.
2. **Floorplanning & Core Boundary:**
   - Core aspect ratio: $1.0$ (square die geometry).
   - Core utilization target: $65\%$ (allowing $35\%$ whitespace for CTS buffer insertion, decap cells, and hold-fixing delay buffers).
   - Core-to-I/O boundary spacing: $35.0\,\mu\text{m}$ clearance on all four sides to accommodate $10.0\,\mu\text{m}$ VDD/VSS power rings and seal rings.
3. **Power Planning & Power Distribution Network (PDN):**
   - Core Rings: Metal 5 (vertical) and Metal 6 (horizontal), width $10.0\,\mu\text{m}$, spacing $4.0\,\mu\text{m}$.
   - Core Stripes: Metal 5 vertical straps ($6.0\,\mu\text{m}$ width, $50\,\mu\text{m}$ pitch) and Metal 6 horizontal straps ($6.0\,\mu\text{m}$ width, $60\,\mu\text{m}$ pitch).
   - Standard Cell Power Rails: Metal 1 followpins connected via `sroute` with stacked multi-cut vias (`VIA1` through `VIA5`).
   - Latch-Up Prevention: Continuous checkerboard insertion of `WELLTAP` cells with a maximum pitch of $30.0\,\mu\text{m}$, strictly conforming to bulk CMOS design rules.
4. **Standard Cell Placement:**
   - High-effort timing-driven and congestion-driven placement (`place_opt_design`).
5. **Clock Tree Synthesis (CTS) via CCOpt:**
   - Cadence Concurrent Clock and Optimization (`ccopt_design`) balances clock skews while simultaneously optimizing datapath gates.
   - Clock tree target: $100\text{ MHz}$ ($10\text{ ns}$ cycle).
   - Insertion delay (latency): $\le 1.50\text{ ns}$.
   - Maximum clock skew across all registers: $< 150\text{ ps}$.
   - Dedicated balanced clock buffers/inverters: `CLKBUF_X4`, `CLKBUF_X8`, `CLKBUF_X12`, `CLKBUF_X16`.
6. **Detailed NanoRouting (1P6M Stack):**
   - Metal 1: Standard cell intracell connections and followpins.
   - Metal 2 & 3: Horizontal and vertical local datapath routing.
   - Metal 4: Long-distance global inter-block signal routing.
   - Metal 5: Vertical power straps and clock distribution trunks.
   - Metal 6: Horizontal power straps, ring distribution, and wirebond pad redistribution.
7. **Silicon Finishing & Decap Insertion:**
   - Insertion of decoupling capacitors (`DECAP16`, `DECAP32`, `DECAP64`) in all vacant placement sites to suppress dynamic $L \cdot \frac{di}{dt}$ supply noise during high-throughput MIMO matrix operations.
   - Filler cells (`FILL1` through `FILL64`) ensure continuous N-well / P-well doping and metal planarization.

#### Innovus P&R Command:
```bash
innovus -files hdl_asic/07_physical_design_asic/scripts/run_innovus_pnr.tcl -log innovus.log
```

### 2.4 Physical Verification (DRC, LVS, Antenna)
Physical verification ensures that the GDSII stream passes all geometric and electrical fabrication rules.

1. **Design Rule Checking (DRC):**
   - Verification with Cadence Pegasus / PVS using the 180nm foundry rule deck (`gpdk180_drc.rul` or `scl180_drc.rul`).
   - Checks minimum feature size, poly endcap enclosure, contact-to-gate spacing, metal min-area, and wide-metal slotting.
2. **Layout Versus Schematic (LVS):**
   - Compares layout extracted SPICE/CDL netlist against the post-synthesis netlist (`mimo_baseband_top_pnr_lvs.v`).
   - Ensures zero short circuits, open circuits, pin swaps, or MOS width/length ($W/L$) mismatches.
3. **Antenna Rule Verification:**
   - Validates that the ratio of metal interconnect area to the thin gate oxide area of connected MOS transistors satisfies foundry antenna ratios ($A_{\text{metal}} / A_{\text{gate}} \le \text{Threshold}$).
   - Any violating long nets automatically have reverse-biased antenna clamp diodes (`ANTENNA`) inserted on input pins.

#### Pegasus Physical Verification Command:
```bash
genus -f hdl_asic/07_physical_design_asic/scripts/run_pegasus_pv.tcl
```

### 2.5 Signoff Static Timing Analysis (STA) via Cadence Tempus
Cadence Tempus performs exhaustive path-based signoff STA using detailed RC parasitic networks extracted by Cadence Quantus QRC (`mimo_baseband_top.spef`).

#### Tempus Signoff Criteria:
- **Setup Timing (Worst Case Corner: SS / 1.62V / 125°C):**
  - Clock frequency: $100\text{ MHz}$ ($T_{\text{clk}} = 10.0\text{ ns}$).
  - Setup Slack target: $\ge +2.00\text{ ns}$ (reflecting our required $20\%$ design margin).
  - Path-Based Analysis (PBA) mode enabled to eliminate graph-based pessimism on critical CORDIC carry chains.
- **Hold Timing (Best Case Corner: FF / 1.98V / -40°C):**
  - Hold Slack: $\ge 0.00\text{ ns}$ across all register-to-register paths under maximum On-Chip Variation (OCV).
- **Signal Slew & Transition Constraints:**
  - Max transition time across all nets $\le 500\text{ ps}$.
  - Max clock transition $\le 350\text{ ps}$.

#### Tempus STA Command:
```bash
tempus -files hdl_asic/07_physical_design_asic/scripts/run_tempus_sta.tcl -log tempus.log
```

### 3.2 Cell Characterization & Physical Views Migration
When porting the pre-silicon design from `gpdk180` to `SCL 180nm`:
1. **Timing Libraries (`.lib`):**
   - The SCL library provides three standard PVT corners:
     - `scl018_slow_1.62v_125c.lib`
     - `scl018_fast_1.98v_m40c.lib`
     - `scl018_typ_1.80v_25c.lib`
   - In `run_genus_synth.tcl` and `viewDefinition.tcl`, simply substitute the `$LIB_DIR` path to point to the authorized SCL cell library directory. Because gate naming follows standard logic primitives (`AND2X1`, `NOR2X1`, `DFFQX1`), the Verilog structural netlist requires zero re-synthesis if identical drive footprints are present.
2. **Physical Layout Execution Views (LEF):**
   - Replace `gpdk180_tech.lef` with `scl018_tech.lef`.
   - Replace `gpdk180_stdcells.lef` with `scl018_stdcells.lef`.
   - Update layer names in Innovus scripts if SCL designates layers as `METAL1`–`METAL6` instead of `Metal1`–`Metal6`.
3. **Design Rule & LVS Decks:**
   - Replace `gpdk180_drc.rul` and `gpdk180_lvs.rul` with SCL's Calibre or Pegasus command files (`scl180_pvs_drc.rul`, `scl180_pvs_lvs.rul`).

### 3.3 I/O Pad Ring Integration & Level Shifting

The 2x2 MIMO Baseband Processor operates at **1.8V internally** to optimize dynamic power, while external system interfaces (FPGA co-processors, RF transceivers, and board ADCs/DACs) operate at **3.3V**. 

#### Pad Ring Architectural Requirements:
1. **Dual-Voltage Power Rails:**
   - `VDD_CORE` (1.8V): Supplies internal baseband processing core.
   - `VSS_CORE` (0.0V): Digital ground return for core logic.
   - `VDD_IO` (3.3V): Supplies high-voltage output driver stages and ESD structures.
   - `VSS_IO` (0.0V): Dedicated quiet ground return for pad drivers.
2. **Level Shifting Architecture:**
   - **Inputs (3.3V Board $\to$ 1.8V Core):** Built directly into SCL input pad cells (`PBDID` / `PIPAD`). The pad receiver translates 3.3V LVCMOS voltage swings to 1.8V internal CMOS levels without external level shifters.
   - **Outputs (1.8V Core $\to$ 3.3V Board):** Output pad cells (`PBDOD` / `POPAD`) contain integrated Low-to-High level shifter circuits powered across the `VDD_CORE` and `VDD_IO` boundary.
3. **Electrostatic Discharge (ESD) Protection:**
   - SCL pad cells incorporate human-body model (HBM) ESD protection diodes rated $> 2000\text{ V}$.
   - Primary and secondary rail-to-rail power clamp cells (`PVDD1_CLAMP`, `PVDD2_CLAMP`) are distributed evenly along the pad ring periphery (minimum 2 clamps per die edge).
4. **Wire-Bonding Geometry:**
   - Standard pad pitch: $90.0\,\mu\text{m}$.
   - Pad opening: $75.0\,\mu\text{m} \times 75.0\,\mu\text{m}$ aluminum bonding area.
   - Package selection: **CQFP-64** or **QFN-48** ceramic package suitable for SCL multi-project wafer (MPW) runs.

## 4. SDC Timing Constraints Specification

The timing constraint file (`hdl_asic/07_physical_design_asic/sdc/mimo_baseband_100mhz.sdc`) dictates the optimization goals across synthesis, P&R, and signoff STA.

### 4.1 Timing Budget Calculations

$$\begin{aligned}
T_{\text{clk}} &= \frac{1}{100\text{ MHz}} = 10.00\text{ ns} \\
T_{\text{setup\_margin}} &= 0.20 \times 10.00\text{ ns} = 2.00\text{ ns} \\
T_{\text{jitter\_skew}} &= 0.20\text{ ns} \\
T_{\text{effective\_period}} &= T_{\text{clk}} - T_{\text{setup\_margin}} = 8.00\text{ ns} \\
\text{Total Setup Uncertainty} &= T_{\text{setup\_margin}} + T_{\text{jitter\_skew}} = 2.20\text{ ns}
\end{aligned}$$

By applying `set_clock_uncertainty -setup 2.20`, we guarantee that every path synthesized to meet $0.00\text{ ns}$ slack will exhibit **at least $+2.00\text{ ns}$ of positive timing margin** when evaluated at nominal silicon speed, comfortably absorbing temperature fluctuations, IR drop, and process variations in 180nm technology.

### 4.2 SDC Code Listing: `mimo_baseband_100mhz.sdc`

```tcl
# ==============================================================================
# SDC Design Constraints for 2x2 MIMO Baseband Processor
# Target Technology: SCL 180nm CMOS / Cadence gpdk180 Baseline
# Nominal Operating Voltage: 1.8V (Core), 3.3V (I/O)
# Target Clock Frequency: 100 MHz (Clock Period = 10.0 ns)
# ==============================================================================

reset_design

# 1. Primary Clock Definition (100 MHz, 50% duty cycle)
create_clock -name sys_clk -period 10.00 -waveform {0.00 5.00} [get_ports clk]

# Virtual reference clock for off-chip interface timing modeling
create_clock -name v_sys_clk -period 10.00 -waveform {0.00 5.00}

# 2. Clock Tree Uncertainty, Jitter, and Transition
# 20% setup margin (2.0 ns over-constraint) + 200 ps clock jitter = 2.20 ns
set_clock_uncertainty -setup 2.20 [get_clocks sys_clk]

# Hold uncertainty accounts for internal clock distribution skew (150 ps)
set_clock_uncertainty -hold  0.15 [get_clocks sys_clk]

# Max slew rate (transition time) on clock network
set_clock_transition 0.35 [get_clocks sys_clk]

# Pre-CTS estimated latency insertion delay
set_clock_latency -source -early 0.80 [get_clocks sys_clk]
set_clock_latency -source -late  1.20 [get_clocks sys_clk]

# 3. I/O Timing Constraints
set input_ports [remove_from_collection [all_inputs] [get_ports clk]]

# Board trace delay + off-chip launch delay: Max 3.0 ns (30% Tclk), Min 0.5 ns
set_input_delay -clock v_sys_clk -max 3.00 $input_ports
set_input_delay -clock v_sys_clk -min 0.50 $input_ports

# External setup time + board trace propagation: Max 3.0 ns (30% Tclk), Min 0.5 ns
set_output_delay -clock v_sys_clk -max 3.00 [all_outputs]
set_output_delay -clock v_sys_clk -min 0.50 [all_outputs]

# 4. Drive Strength & Output Load Modeling
set_driving_cell -lib_cell INVX4 -pin Y -library [get_libs -of_objects [get_lib_cells */INVX4]] $input_ports
set_load -pin_load 0.050 [all_outputs]

# 5. Design Rule Constraints (DRC)
set_max_transition 0.50 [current_design]
set_max_fanout 16 [current_design]
set_max_capacitance 0.200 [current_design]

# 6. Timing Exceptions
if {[sizeof_collection [get_ports -quiet rst_n]] > 0} {
    set_false_path -from [get_ports rst_n]
}

# Quasi-static configuration registers (AXI4-Lite thresholds)
set static_regs [get_pins -quiet {*reg_thresh*/Q *reg_config*/Q *reg_power_budget*/Q}]
if {[sizeof_collection $static_regs] > 0} {
    set_multicycle_path 2 -setup -from $static_regs
    set_multicycle_path 1 -hold  -from $static_regs
}
```
